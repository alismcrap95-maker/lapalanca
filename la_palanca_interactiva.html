¿Qué es una Palanca? 🤔

¿Alguna vez has intentado levantar algo MUY pesado y no pudiste? ¡No te preocupes! La palanca es una máquina simple mágica. Es como un súper poder de la física que nos ayuda a mover objetos pesados usando muy poca fuerza. ¡Solo necesitas una barra rígida y un punto para apoyarte!

¡Mira este video bien bacano para entenderlo mejor! 🎬

¡Los 3 Elementos Secretos! 🤫

Toca cada tarjeta para descubrir sus secretos.

🔺

Fulcro

(Punto de apoyo)

Toca para girar 🔄

Es el punto fijo donde se apoya y gira la palanca. ¡El punto de equilibrio!

💪

Fuerza

(O Potencia)

Toca para girar 🔄

Es el "empujón" o la fuerza que TÚ aplicas para intentar mover el objeto.

🐘

Resistencia

(La Carga)

Toca para girar 🔄

¡Es lo que queremos mover! El peso del objeto que se resiste a ser movido.
